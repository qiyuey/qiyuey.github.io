美联储不是资产定价的总开关

Updated: 9 Sep, 2026
· 2256 字 · 6 分钟 |

资产之间没有固定的联动公式。判断方向之前，先分清这次是增长、通胀还是资金需求在推动。

2020 年 3 月，美股十天内三次熔断，黄金下跌，连美国国债也在被抛售。平时被当成对冲组合的三类资产一起跌，问题出在”避险”这个解释上。当时市场缺的不是安全，是现金。保证金追缴和基金赎回逼着机构卖掉最容易变现的东西，而美国国债和黄金刚好最容易变现。

这类现象没法用”降息利好股票和黄金”来解释。美联储确实通过利率影响所有资产，但利率只是其中一条线。美元、美债、美股和黄金各自回应不同的东西，同一次利率变化推出不同结果，才是常态。

    A["增长、通胀与资金需求"] --> B["政策预期"]
    B --> C["利率"]
    C --> D["美债价格"]
    C --> E["股票折现率"] --> J["股票估值"]
    A --> F["企业盈利预期"] --> J
    C --> G["相对利差 → 美元"]
    C --> H["实际利率 → 黄金"]
    I["避险与现金需求"] --> D
    I --> G
    I --> H

四条线同时在动，分析要做的是找出占上风的那一条。

  • 利率决定资金成本，直接压在美债价格、股票估值和持有黄金的机会成本上。
  • 盈利决定美股能不能扛住利率上升。
  • 相对利差影响美元，看的是美国资产相对海外资产的吸引力。
  • 资金需求可能主导危机里的短期方向，看市场想保住资产还是急着拿现金。

长期利率不跟着短端照走

美联储设定联邦基金利率的目标区间，并通过政策工具引导隔夜市场利率。十年期美债收益率是另一回事，它装的是市场对未来十年利率路径的判断，可以拆成两块，一是未来短期利率的预期平均值，二是期限溢价（term premium），即投资者承担长期利率风险所要求的补偿。纽约联储的期限溢价模型按这个分解估算，期限溢价需要估计，也可以为负。

美联储也会通过前瞻指引和资产购买影响长期利率，但长端不会机械跟随当期政策利率。降息和长端收益率上行可以同时发生，只要远期利率预期或期限溢价升得更多。预期部分已经包含通胀，不需要再加一遍通胀预期。

政策落地当天，还要看实际决策和政策指引与此前预期的差。市场原本期待降 50 个基点，实际只降 25 个，虽然还是降息，力度却弱于已经计入价格的部分。只看”降息”两个字判断当天走势，等于漏掉了市场提前交易过的那一段。

债券方向明确，股票多两笔账

同一只现金流确定的固定利率债券，价格与到期收益率反向变化。所以”美债涨了”必须说清涨的是价格还是收益率，SEC 的债券说明把这层关系讲得很直白。

用一张一年后支付 100 美元的零息债券举例。花 95 美元买，到期收益率约 5.26%；花 98 美元买同一张，收益率只剩 2.04%。付的钱越多，同一笔未来收入能提供的回报率就越低。

股票要比债券多算两笔账，一是未来现金流会不会变多，二是投资者要求多少风险补偿。股权折现率可以简化成无风险利率加股权风险溢价（equity risk premium），折现率越高，同一笔未来现金流今天越不值钱（美联储的资产估值分析）。

风险补偿这一项最容易漏掉。无风险利率从 4% 降到 3%，股权风险溢价却从 4% 升到 7%，折现率就从 8% 升到 10%。国债利率在降，股票估值照样承压。

    A["收益率为何变化？"] --> B["增长预期改善"]
    A --> C["通胀压力上升"]
    A --> D["衰退担忧加深"]
    B --> E["盈利预期同步上修"]
    E --> F["盈利占上风，美股仍可上涨"]
    C --> G["折现率抬升，盈利跟不上"]
    G --> H["美股下跌"]
    D --> I["收益率下行<br/>但盈利下修、风险补偿上升"]
    I --> J["美股仍可下跌"]

利率变化要和盈利、风险补偿放在一起看，才能解释股票的反应。

美元看相对，黄金看实际

美元汇率是美元相对另一种货币的价格，美国利率只提供了比较的一侧。还要看海外利率怎么变，以及美国资产相对海外资产的吸引力有没有改变（美联储政策传导说明）。

黄金不付息，买它就放弃了其他资产的利息收入。判断黄金承受的利率压力，要看扣掉预期通胀后的实际利率（世界黄金协会的利率研究）。

资产优先看什么传导方向与条件
美元美国与海外的预期利差美国相对利差扩大，通常支持美元
美元美元融资需求急需美元偿债或补保证金，会增加美元需求
黄金实际利率实际利率上升，持有黄金的机会成本变高
黄金美元汇率美元走强，通常压制美元计价黄金
黄金避险与储备配置需求买盘增强可以抵消部分利率压力

实际利率近似等于名义利率减预期通胀，两者期限必须对齐。十年期收益率不能直接减最近公布的同比 CPI。市场上通常用通胀保值国债 TIPS 的收益率观察实际利率，但这个价格里也混着流动性等因素（圣路易斯联储的说明）。

所以通胀高不等于黄金必涨。加息把实际利率推得更高，黄金同样承压；反过来，利率带来的压力也可能被央行购金这类买盘抵消。

跨币种比较还漏不得一条纪律，收益率与汇率变化必须对应同一段持有期。同期美元资产赚 5%，美元对本币贬值 4%，未对冲的本币回报约为 1.05 × 0.96 − 1 = 0.8%，不计税费。年化收益率不能拿去和十年累计的汇率变化相减。

危机里先分清避险和抢现金

“害怕亏损”和”马上缺钱”引出的是两种交易。前者让人买入安全资产，后者逼人卖出容易变现的资产。

flowchart TD
    A["危机加深"] --> B["担心未来亏损"]
    A --> C["急需现金应付赎回与保证金"]
    B --> D["增加避险配置"]
    D --> E["支持美债或黄金买盘"]
    C --> F["出售容易变现的资产"]
    F --> G["美债、黄金也可能被卖出"]
    C --> H["需要美元付款"]
    H --> I["增加美元需求"]

2020 年 3 月的三件事把这层区别坐实了：

当时发生了什么说明了什么
投资者大量抛售美国国债，做市商承接能力被打满安全资产同样会遭遇流动性冲击（BIS 研究）
投资者卖出黄金换取现金、补足保证金容易变现有时恰恰是资产被卖出的原因（世界黄金协会同期分析）
美元融资市场承压，多家央行出手提供美元流动性美元需求还来自偿债与融资（BIS 危机回顾）

判断危机中的资产方向，关键是资金需求的性质，而不是危机发生在哪个市场。

四种情景下的对照

把四类资产放回同一个情景里比较，美债指中长期固定利率国债，黄金指美元计价黄金。表中列的是主要影响，实际方向仍取决于哪条线占上风。

主导情景利率与美债美股美元与黄金
通胀回落，增长仍稳降息空间打开，收益率下行利于债价盈利稳定，折现压力减轻相对利差收窄压低美元；实际利率下行支持黄金
通胀超预期，政策趋紧收益率上行，债价承压折现率上升压低估值相对利差扩大支持美元；实际利率上行压制黄金
衰退担忧加深降息预期与避险买盘支持债价盈利下修可能盖过降息利好美元受降息与避险两股力量拉扯；黄金获避险支持
美国增长强于海外利率预期上调，债价可能下跌盈利改善可支持上涨美国资产吸引力支持美元；黄金仍要看实际利率

美股和收益率一起涨，可以由盈利改善解释；股债一起跌，可以由通胀和紧缩预期解释。资产之间不必始终保持同一种关系。

先定原因，再看方向

看行情时第一步是辨认增长、通胀或资金需求发生了什么变化，再沿利率、盈利、相对利差和避险需求往下推。单日涨跌不足以确认原因，这是这套框架的限度。

这个顺序也决定了该找什么证据。用增长改善解释美股上涨，就要看盈利预期有没有上修；用美元短缺解释美元走强，就要看融资压力有没有上升。

同一个冲击会沿不同渠道影响各类资产，方向不一致并不意味着主导原因已经切换。理解资产联动，要找出哪种解释能同时说清利率、盈利预期和资金需求的变化。
